# Quickstart

Démarrer l'annotation en 30 secondes.

## 1. Démarrer le serveur

Dans le terminal, à la racine du projet :

```bash
docker-compose up --build
```

## 2. Accéder à l'interface

Ouvrir [http://localhost:8501](http://localhost:8501) dans le navigateur.

## 3. Annoter

1.  En l'absence de fichier, en créer un exemple dans le dossier `data/` ou utiliser l'upload.
2.  Sélectionner un fichier dans le menu déroulant à droite.
3.  Créer un label (ex: `TEST`) dans la barre latérale gauche.
4.  Saisir un mot présent dans le texte (ex: `bonjour`) dans le champ "Texte à annoter".
5.  Cliquer sur **Valider**.
